# Changelog

## 1.0.1

- Clarify the project name as WordPress PDF Catalogue Flipbook Builder
  (WordPress PDF 产品目录翻页插件生成器).
- Rename the Skill and public source root to `build-wordpress-pdf-catalogue-flipbook`.
- Align the UI metadata, invocation examples, bilingual documentation and GitHub
  publishing instructions with the new name.
- Default generated plugin display name: WordPress PDF Catalogue Flipbook.
- Preserve the installed plugin slug, main filename, shortcode and block identifier;
  no reader behavior or existing page content changes.

## 1.0.0

- Independent WordPress-first catalogue Skill and installable plugin builder.
- PDF/page-image conversion, aspect-preserving WebP variants, searchable metadata
  and product hotspots; validated ZIP and SHA-256 build report.
- Gutenberg block and shortcode, cover-first modal or inline reader, local assets,
  mobile single pages, desktop spreads, page jump, thumbnails, search and zoom.
- Safe path resolution, escaped markup, multiple instances and no-JavaScript links.
- Tests, fictional demo generator, bilingual documentation and GitHub CI.
- Versioned manifest/media URLs, cancellable page-turn render lifecycle,
  right-page zoom selection and stale-request guards.
