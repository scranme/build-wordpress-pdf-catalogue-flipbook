A self-contained product catalogue reader generated by WordPress PDF Catalogue Flipbook Builder (build-wordpress-pdf-catalogue-flipbook).

== Installation ==

1. In WordPress, open Plugins > Add New Plugin > Upload Plugin.
2. Upload this plugin ZIP, install it, and activate it.
3. Add the Product Flipbook block to a page, or use a Shortcode block containing [product_flipbook catalogue="default"].
4. Publish the page and add it to your site navigation.
5. Click the cover on the published page to open the reader.

Settings > Product Flipbook lists every bundled catalogue and its shortcode.
Use [product_flipbook catalogue="default" mode="inline"] to expand inside the page.

== Compatibility ==

The plugin is independent of the active theme and does not require jQuery or a page builder.
It supports the block editor, classic editor shortcodes, and page builders that execute WordPress shortcodes.
Assets load when a flipbook is rendered. The theme must call wp_head() and wp_footer(), as standard WordPress themes do.
If a JavaScript delay optimizer prevents the first click from working, exclude wpcf-page-flip and wpcf-runtime from that optimizer.
Keep one generated flipbook plugin active on a site. Several catalogues may be included in its catalogues/ folder, and several readers may be shown on one page.

== Updating ==

Rebuild with the same plugin slug and a higher version, then upload the new ZIP and replace the existing plugin.
The plugin directory is replaced during an update; keep source files and unpublished work separately.
The plugin does not create, publish, edit, or remove WordPress pages or menus.

== Privacy ==

The reader sends no analytics, form submissions or external API requests. Its scripts and catalogue assets are bundled locally.
Page links and an optional download allow public access to the bundled catalogue. Do not install confidential content on a public website without access controls provided by the website.

== Troubleshooting ==

If a shortcode appears as plain text, confirm this plugin is active and that the text is inside a Shortcode block, not a Code block.
If a catalogue is missing, use Settings > Product Flipbook to copy its exact identifier.
If the host rejects a large ZIP, increase the host upload limit or install the extracted plugin directory through the hosting file manager or SFTP.
The individual page-image links remain usable if JavaScript is unavailable.
